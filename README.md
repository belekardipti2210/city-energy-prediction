City Energy Consumption Analysis & Prediction System ⚡

This project, developed during my Data Science Internship at IBI Teams, focuses on analyzing and predicting city-wide electricity consumption using a synthetic dataset (365 days, 5 zones). 
I used Python, Pandas, NumPy, Matplotlib, and Scikit-learn to generate and preprocess data, visualize trends, and build ML models (Random Forest & Linear Regression) for next-day demand prediction. 
The system identifies patterns between temperature, humidity, events, and energy usage, achieving an accurate prediction with low MAE and providing an interactive console for real-time forecasting.
